This project is a turtle robot designed to draw custom shapes and symbols. In the demo video, the robot is programmed in Python to draw a simple bicycle symbol, showing how the system can follow planned motion paths and create precise pen output.

This work was developed as part of my Product Development class (in 2022), where the goal was to plan and build a complete product from concept to prototype. The project involved mechanical assembly, PCB design, development of the pen mechanism, and integration of the hardware into a working robot platform.

The full build required combining software, electronics, and mechanical design into one system. From designing the structure and motion system to assembling the components and testing the drawing behavior, this project focused on turning an initial product idea into a functional prototype.
